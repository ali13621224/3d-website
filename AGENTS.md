# AGENTS.md

## What this is

ÉCLAT Jewelry & Diamonds — a client-side luxury storefront: Vite + React with
plain CSS (no CSS framework). There is **no backend, no database and no
third-party API**, so there is nothing to put in `/run/base44/app.env`.

## Running in the Base44 sandbox

Use `docker-compose.base44.yml` — not any other compose file:

```sh
docker compose -f docker-compose.base44.yml up -d --build
```

- **Dependencies install at container start** into the `node_modules` named
  volume (never the repo). First boot takes ~1 minute; the healthcheck has a
  120s `start_period`.
- **`package-lock.json` is generated by that install** and should be committed so
  later installs are reproducible.
- **The dev server must stay a dev server.** `vite` serves the source on port
  3000; a production build (`dist/`) would break the edit-in-place loop.
- **Sandbox host/origin overrides are gated on `BASE44_PREVIEW_MODE === "1"`** in
  `vite.config.js`: `allowedHosts` gains `.<BASE44_SANDBOX_HOST_DOMAIN>` (the
  sandbox id rotates) and HMR is pinned to `wss` on port 443 because the preview
  proxy terminates TLS. With the variable unset, plain `npm run dev` behaves
  exactly like stock Vite.

## Non-obvious things worth knowing

- **Routing is hand-rolled** (`src/lib/router.jsx`) — no router dependency. Real
  URLs via `history.pushState`, and the provider wraps `pushState`/`replaceState`
  so programmatic navigation is observed (pushState alone fires no event, so a
  bare `popstate` listener would miss it). Vite's SPA fallback serves
  `index.html` for unknown paths, so a refresh on a deep route re-renders it.
  Route matching lives in the `Routes` component in `src/App.jsx`.
- **Every jewellery visual is inline SVG** (`src/components/art/JewelryArt.jsx`) —
  there are no image files and no pre-rendered assets. `METAL_TONES` drives every
  gradient, which is why the metal switcher both re-lights the piece and
  re-prices it.
- **Prices are derived, never stored**: `computePrice()` in `src/lib/pricing.js`
  is `base × (carat / defaultCarat)^1.5 × metal factor` (platinum 1.18). `SPOT`
  is a static reference used for the "value at spot" line on the PDP and in the
  specification dialog — swap it for a real feed without touching the views.
- **Bag, wishlist and currency persist in `localStorage`** under
  `eclat.boutique.v1`. Data written there survives a reload; clear that key to
  reset the boutique.
- **Fonts load from Google Fonts** (`index.html`, Cormorant Garamond + Plus
  Jakarta Sans) with serif/sans fallbacks, so the layout holds without network.
- **Checkout is deliberately not connected** — no payment provider is wired up,
  and the button says so rather than pretending to charge.
- The gold-ring cursor and all reveals are gated on `prefers-reduced-motion` /
  fine-pointer capability and degrade to the native cursor on touch devices.

## Verifying it works

1. `docker compose -f docker-compose.base44.yml ps` → `web` is `healthy`.
2. `curl -s http://localhost:3000/ | grep root` returns the Vite-served HTML.
3. Home renders the emerald hero ("Diamonds For Life's Most Beautiful Moments")
   with 7 halo categories, 4 trust cells, 2 editorial banners and 5 best sellers.
4. Switch a product card's metal to platinum — price moves `$8,500 → $10,050`.
   Add to Bag opens the bag drawer; the stepper and remove work; the wishlist
   heart increments the header badge.
5. `/product/solitaire-grace-ring` shows 4 gallery views, the metal/carat
   switchers re-price, the specification dialog lists the 4 Cs, and the ring size
   guide resolves 16.5 mm → US 6.
6. Console must be free of errors at every route.
